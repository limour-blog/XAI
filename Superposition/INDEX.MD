# Superposition：从玩具模型到 Claude 3 Sonnet

**渐进式阅读入口（Level 0）**：先从下表选论文，再从论文索引读摘要、实验、图表或附录。

这里的**特征叠加**是指神经网络在有限的激活维度里用非正交方向表示更多特征。第一篇在已知输入特征的玩具模型里考察叠加为何形成；第二篇在生产级语言模型里测试能否用稀疏自编码器把表征分解成可解释的方向。

| 论文 | 一句话结论 | 入口 |
| --- | --- | --- |
| **01 · Toy Models of Superposition** (2022) | 在输出带 ReLU 的玩具模型中，90% 稀疏度下，五个特征在二维空间排成五边形，但会产生干扰。 | [论文 01](01/INDEX.MD) |
| **02 · Scaling Monosemanticity** (2024 原刊；2026 arXiv 版) | 在 Claude 3 Sonnet 中间层训练最多约 3400 万特征槽的稀疏自编码器，提取出部分跨语言和模态、能通过干预改变输出的可解释特征，但字典并不完备。 | [论文 02](02/INDEX.MD) |

建议按 01 → 02 阅读。第一篇的相变与多面体几何是特定玩具模型的结果，不应直接视为第二篇在 Sonnet 上验证的结论。
