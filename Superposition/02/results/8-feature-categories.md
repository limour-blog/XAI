# A survey of feature categories

- **People:** Directions for well-known individuals activate on names and relevant surrounding context. These examples distinguish referents from individual name tokens: descriptions and images can activate person features.
- **Countries:** Features respond to geographic and historical associations, not just country names. Countries, cities, and finer-grained locations can appear at different scales of the dictionaries.
- **Code:** Directions for low-level syntax or programming concepts, visualized together as binary active/inactive signals, resemble syntax highlighting. Compare the [context-sensitive function features](4-sophisticated-features.md). [Figure 029](../figures/figure-029.md).
- **List positions:** Some features track where a list item occurs. This is an example of an abstract structural representation rather than a topic. [Figure 030](../figures/figure-030.md).

The examples show diversity, not a random census. The [completeness study](7-completeness.md) uses separate criteria for dedicated representations.
