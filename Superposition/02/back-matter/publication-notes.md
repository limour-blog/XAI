# Publication notes

## Author contributions

The source separates infrastructure and algorithm work from paper results and other work. Contributions include cluster orchestration, activation collection and shuffling, tensor parallelism, baselines, tools for interventions and feature exploration, scaling analysis, feature evaluations and case studies, visualizations, project direction and writing. The full contribution list with individual credit is in the [TeX appendix](../../../TeX/Superposition/arXiv-2605.29358v1/main.tex) and [HTML version](https://transformer-circuits.pub/2024/scaling-monosemanticity/index.html).
