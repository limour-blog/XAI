# 3.1 单层线性注意力与一步梯度下降

训练所得单头 LSA 与按命题 1 构造的一步 GD 在预测值和查询梯度上高度对齐，且在多组超参数下成立。除了比较输出，作者做了三项测试：

1. **权重插值。** 消除标量重参数化后，训练所得 $W_{PV}$、$W_{KQ}$ 与构造高度相似。对相应乘积取中点，损失与两端接近；这比只比较最终误差更直接地支持机制匹配。
2. **分布外测试。** 分别改变输入区间为 $[-\alpha,\alpha]$、或把教师权重乘以 $\alpha$（训练时 $\alpha=1$），Transformer 与 GD 都呈现类似变化。匹配并不代表绝对鲁棒：较大的输入尺度使曲率升高，可让已调定的 GD 步长失稳。
3. **重复执行。** 仅按一步任务训练的单层，在通过 $\lambda=0.75$ 阻尼缩小更新后，可以重复施加；其损失轨迹与同样阻尼的 GD 一致。附录对比了不同阻尼值。
