# 4. 自注意力层会构造回归任务吗？

此前的实验直接提供 $(x_j,y_j)$。这里把输入与标签放进交替的 token：$e_{2j}=(x_j)$、$e_{2j+1}=(0,y_j)$，并拼接位置编码。**命题 3** 给出线性或近似 softmax 注意力的单头构造，使注意力可从相邻位置复制内容，得到命题 1 所需的配对表示。

在训练的两层模型中，最终损失接近一步、而非两步 GD，且约慢一个数量级。训练跃迁前，第一层输出对下一 token 的偏导变大，而对非相邻 token 的依赖保持较弱。这支持“第一层配对、第二层更新”的解释。虽然理论上可以构造线性复制头，作者在此训练实验中需要第一层带 softmax，未能用纯线性注意力训练出该行为。

这与[归纳头论文](../../arXiv-2209.11895v1/INDEX.MD)共享“利用注意力复制信息”这一思路；实验关注的是在相邻 token 间组装回归样本，而不是证明语言模型的归纳头一般都在做 GD。
