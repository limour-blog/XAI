# 3.3 在深层特征上做梯度下降：非线性回归

**命题 2。** 若 MLP 先计算特征 $m(x)$，后续注意力就可以按命题 1 的构造下降 $\frac1{2N}\sum_i\|Wm(x_i)-y_i\|^2$。内层模型对特征 $m(x)$ 是线性的，但对原输入可以是非线性的；诱导的核为 $k(x,x')=m(x)^\top m(x')$。

在正弦波任务中，作者比较完全学习的 MLP + LSA 与固定最后一层为 GD 构造的对照模型。两者在 MLP 后的初始预测和一次上下文更新后的最终预测都相近，损失和关于查询的导数也对齐；后者不是对全局函数等价的证明。Transformer 的 MLP 可以同时处理输入和目标，与只用 $x$ 构造特征的典型元学习方法不同。
