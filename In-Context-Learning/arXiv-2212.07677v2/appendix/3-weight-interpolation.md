# A.3–A.4 权重插值与可视化

设 $W_{KQ}=W_K^\top W_Q$、$W_{PV}=PW_V$，用训练所得 $W_{KQ}$ 对角元素的平均值 $\beta$ 消除缩放自由度：$W_{KQ}\leftarrow W_{KQ}/\beta$、$W_{PV}\leftarrow\beta W_{PV}$。分别对缩放后的乘积和理论构造的对应乘积取平均，用这两个中点组成插值模型。应用于 GD 和循环模型的 GD++；不共享权重时各层尺度还会相互影响，这个简单校准不能普遍奏效。

[图 9](../figures/figure-9-weights.md)对比了单层和三步循环 LSA 的两个乘积。后者的 $PW_V$ 输入块出现与曲率校正对应的对角项，最后一个对角项与有效学习率相联系。
