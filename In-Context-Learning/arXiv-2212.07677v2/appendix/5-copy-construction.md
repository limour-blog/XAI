# A.5 命题 3：用位置编码选择相邻 token

用单位向量 $p_j$ 编码位置，设移位矩阵 $S$ 的次对角线为 1，使 $Sp_j=p_{j+1}$。对拼接 token $(z_j,p_j)$，通过投影令查询的位置块为 $Sp_j$，键的位置块为 $p_i$，并令内容块不影响匹配。于是 $k_i^\top q_j$ 恰选中 $i=j+1$。用值投影把该位置的内容 $z_{j+1}$ 与位置抵消项 $-S^\top p_{j+1}=-p_j$ 写入下半块，保留 $z_j$。在需要的偶数位置，这等价于拼接输入及其标签。带 softmax 时可把匹配分数放大，使注意力权重趋近同样的单点选择。

其他位置也可能收到相邻内容。作者讨论了额外用注意力头抵消不需要的 token；同时指出对语言而言，相邻或非相邻的多种配对可能本来就有用。此处是存在性构造，训练证据见[结果 §4](../results/4-token-copying.md)与[图 5](../figures/figure-5-copying.md)。
