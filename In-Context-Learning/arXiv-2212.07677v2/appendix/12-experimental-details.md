# A.12 实验细节与固定任务集

- Adam（Optax，默认参数）；深度 $K<3$ 的学习率为 0.001，其余为 0.0005；批大小 2,048，梯度全局范数裁剪到 10。
- Haiku fan-in 截断正态初始化，标准差 $0.002/K$。没有正则化。对 $K>2$ 的模型，为稳定训练将 token 裁剪至 $[-10,10]$。
- 使用位置编码时维度为 20，拼接到各 token。Q、K、V 投影均为方阵。GD 从 $W_0=0$ 开始；对 $\eta,\gamma$ 的元学习复用同样设置，通常所需迭代更少。
- 固定任务集实验反复在同一批任务上训练单层线性注意力，大小 $B$ 为 128、512、2,048、8,192。即使数据量不大，学习出的映射仍与理论构造近似对齐。
