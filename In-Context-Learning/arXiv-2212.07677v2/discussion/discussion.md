# 5. Discussion：机制证据与适用范围

对于简单回归，单层的数学构造及训练后的权重校准说明 Transformer 的前向传播可以实现梯度学习；深层实验提供了对 GD++ 的支持。把这些现象放在元学习框架中，参数训练是外循环，前向传播中对上下文数据的变换是内循环。注意力复制还可能先构造可供内循环使用的训练对。

理论中的线性注意力构造与实验里观察到的近似对齐不是同一个结论。研究没有在大语言模型上验证普遍梯度下降机制，也未系统研究噪声、权重正则化或 logistic 回归。带 softmax 和 LayerNorm 的模型与 GD 的匹配弱于线性模型；权重插值的证据也不能直接推广到各层独立的深层模型。

作者建议后续研究单注意力层内的精确回归求解（declarative nodes）、更大模型的机制解释、为不同内循环算法调整架构或训练方式，以及由 HyperTransformer 直接生成目标网络权重的路径。
