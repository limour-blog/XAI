# 合成任务：Base、Hint、CoT

| 设置 | 训练与评估 |
|---|---|
| Base | 监督直接输出的答案，评估最终答案正确率。 |
| Hint | 按输入前缀提供中间标签，但预测的中间值不作为之后的输入；评估最终答案。 |
| CoT | 教师强制预测串行的中间序列和最终答案；评估所有中间与最终 token 均预测正确的概率。 |

CoT 的全序列正确率是不带教师提示自回归生成时最终答案正确率的下界：完整轨迹正确能保证答对，但错误轨迹也可能答对。Hint 控制的是额外监督，不能等同于生成并读回中间结果。

按任务和长度从随机初始化训练，每步在线采样新的合成数据。使用 nanoGPT、Adam、batch 64、宽度 512、8 个注意力头、float16、无 dropout；深度变化。学习率 $10^{-5}$，前 2,000 步从 $10^{-6}$ 线性预热，总预算 $10^6$ 步；权重衰减 0，$\beta=(0.9,0.95)$，梯度裁剪阈值 1.0。
