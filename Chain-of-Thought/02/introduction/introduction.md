# 中间解码是否扩展表达能力？

读取后立即答复的对数精度 Transformer 受 uniform TC⁰ 电路上界约束。在标准复杂度分离假设下，有限自动机模拟、有向可达性等顺序任务不能都由这类模型完成。自回归模型则可生成中间 token 并把它们读回；每个 token 都能作为递归状态或存储更新。

本文不要求中间 token 是自然语言。问题是：允许 $t(n)$ 个步数时，理论上存在什么可精确判定的语言？从对数、线性、多项式三个预算出发，分别给出 [总体结论](../results/1-expressiveness.md) 和时间、空间模拟界。与 [Li 等人的模型](../../03/INDEX.MD) 相比，本篇关注统一解码器和图灵机，而非允许随输入长度重设参数的电路家族。
