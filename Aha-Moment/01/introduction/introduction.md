# Introduction

自回归语言模型逐 token 从左到右作决策。对初始选择会限制后续可行性的任务，模型即使掌握相关知识，也未必能在单条采样轨迹里探索或者修订早期选择。作者借用双过程理论和 Newell、Shaw、Simon 的问题空间搜索，将部分解表示为树节点、修改部分解的操作表示为边。

[框架图](../figures/figure-1-schematic.md)对比直接生成、多链投票和在中间状态上搜索。核心区别是用模型生成和判断有语义的中间步骤，再由外部搜索机制前瞻或回溯，而不是从 token 概率直接推断部分解的价值。实证覆盖[三种任务](../tables/table-1-task-overview.md)。
