# 从模仿推理轨迹到用结果反馈探索

链式提示和监督微调能改进推理，但需要生成或标注过程样例。本文的问题是：从训练过的基座出发，只约束答案正确性和输出格式，是否足以在后训练中促进检查、反思与改换解法？[R1-Zero](../methods/2-zero-rewards.md)跳过初始监督微调，直接以 [GRPO](../methods/1-grpo.md)优化。没有使用人工标注的推理轨迹作这一阶段的监督，并不等于基座在预训练中未见过推理文本。

Zero 的语言混杂、可读性与一般任务能力促使作者另外构建 [R1 流水线](../methods/3-r1-pipeline.md)。随后通过[蒸馏](../results/11-distillation.md)把较强模型的输出用于训练更小模型。
