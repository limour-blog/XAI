# R1 的四阶段训练与奖励

1. **Dev1：** 收集几千条经筛选与改写的长 CoT，从 V3-Base 做冷启动 SFT，强调可读性和语言一致性。
2. **Dev2：** 面向可验证的推理进行第一次 RL，加入语言一致性奖励，即 CoT 中目标语言单词占比。学习率 $3\times10^{-6}$、KL 0.001、GRPO clip 比率 $\epsilon=10$，采样温度 1、长度上限 32,768。
3. **Dev3：** 对 Dev2 输出做拒绝采样获得推理数据，加上通用与软件工程数据，再对 V3-Base 做约 80 万条样本的 SFT。
4. **R1：** 第二次 RL 共 1,700 步，温度 0.7，最后 400 步才加入一般指令数据和模型偏好奖励。推理数据使用规则奖励；一般数据使用对应的奖励模型加格式奖励；语言一致性奖励同时用于两类数据。

**有用性**只评最终总结，用约 66,000 个成对偏好样本训练。DeepSeek-V3 对每对判断 4 次并随机对调 A/B，保留平均差距 $\Delta>1$ 的样本，并控制长短分布。**安全性**评完整输出，对 106,000 个提示对应的生成结果使用安全/不安全标签、逐条训练。两者训练批量 256，学习率 $6\times10^{-6}$，1 epoch，训练长度上限 8,192 token。
