# Description of RL data and tasks

| 数据类型 | 提示数 | 问题类型 | 输出类型 |
|---|---:|---|---|
| Math | 26K | 定量推理 | 数值、表达式或方程 |
| Code | 17K | 算法和错误修复 | 代码解答 |
| STEM | 22K | 选择题 | 选项 |
| Logic | 15K | 选择题或定量推理 | 选项或数值 |
| General | 66K | 有用性、无害性 | 排序后的回答 |

以上为原表 `tab:rl_data` 数值；正文另报告 8K 修复题及 12,000 道无害性问题。
