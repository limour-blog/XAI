# GPT 算术：固定输出、改变指标

用 2-shot 测两位整数乘法和四位整数加法；2023-03-15 API 提供 350M、1.3B、6.7B、175B 四个规模。作者预测：换为较平缓的指标可恢复平滑趋势；增加测试样本可在非线性指标下分辨非零小模型表现；目标长度影响应分别近似几何和准线性。

结果：目标答案为 4 或 5 位时，整串准确率呈跃升。同一输出改算 token 编辑距离时，随规模平滑改善；目标长度从 1 到 5 时，编辑距离增加近似准线性。这项对照没有重新训练模型或为两个指标生成不同答案。
