# 何谓“像涌现”的曲线？

本文从 [Wei 等的定义](../../01/methods/1-emergence-definition.md)中抽出两个性质：从无到有的**尖锐性**，以及不能从已测小规模预见转折点的**不可预测性**。原案例见[图 1](../figures/figure-1-prior-emergence.md)。

作者追问：在任务、模型家族、生成输出不变时，能否仅靠改变评分改变这种判断？Exact String Match 只在整串完全相同时给 1；Multiple Choice Grade 仅在正确选项概率排名第一时给 1。换成能记录局部改善的指标或增加测试样本，可能看见原本接近零的一段仍在改善。
