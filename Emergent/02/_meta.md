## Abstract

**Background:** Sharp and unpredictable benchmark transitions have been interpreted as changes in language model abilities. **Methods:** An illustrative model links smoothly changing token probabilities to exact match and edit distance; experiments compare metrics, test-set resolution and target length on GPT arithmetic, reanalyze BIG-Bench and construct examples on vision tasks. **Results:** Arithmetic curves become smooth with edit distance; larger test sets reveal above-chance accuracy. Over 92% of hand-annotated BIG-Bench emergence cases use exact string match or multiple-choice grade. LaMDA curves smooth under Brier score on the tested tasks. **Conclusion:** Metrics and measurement resolution explain the selected observations without ruling out genuine changes in behavior elsewhere.
