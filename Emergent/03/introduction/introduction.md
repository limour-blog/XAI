# 下一 token 的损失为什么能学到更远的信息？

下一 token 预测（NTP）拟合 $p(x_{t+1}\mid x_{\le t})$，但模型仍可能重建棋盘、语言的抽象结构，或让未来 token 的信息可从当前状态解码。本文研究特征在训练中怎样形成，而不只问训练后它在哪条电路中被使用。

作者按梯度路径提出[直接学习、预缓存、电路共享](../methods/2-gradient-decomposition.md)，然后用训练消融与沿轨迹归因，解释玩具任务、棋盘和自然文本。对只能访问终点的 Gemma 2，则另用[局部干预指标](../results/4-gemma-pre-caching.md)。
