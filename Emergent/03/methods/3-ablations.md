# 消融预缓存和电路共享

- **Myopic training**：阻断某位置的损失向其他位置的激活反传；在注意力中对非当前位置的 K、V 停梯度，保留原有前向读取。由未来损失选育“当下用不着”的中间特征的路径被切断。多层注意力组合（如 induction head）可能因此更难学到。
- **$m$-untied training**：以位置 $m$ 为界，前后两段各用一组权重，后段仍可读前段 KV；后段直接学到的电路不再通过权重共享自动出现于前段。
- **合并消融**：前段既不收后段传回的跨位置梯度，也不共享参数，构成对 NTP-useless 特征训练信号的对照。
